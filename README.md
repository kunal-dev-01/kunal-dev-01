## About Me

Hey, I'm **Kunal** — a full-stack developer with **around 3 years of hands-on experience** building web applications, backend services, and production infrastructure.

I started with the **MERN stack**, explored a wide range of technologies, and gradually moved deeper into **Go and backend engineering**. Today, I enjoy working across the full lifecycle of a product: designing APIs and data models, building interfaces, deploying services, and keeping systems reliable and cost-efficient.

I'm especially interested in the engineering behind products: how services communicate, how data is stored and recovered, how infrastructure costs are controlled, and how software stays secure and maintainable as it grows.

- Building full-stack applications and backend services.
- Working with **Go**, Node.js, TypeScript, and modern web technologies.
- Designing and managing data systems with PostgreSQL, MongoDB, Redis, and search infrastructure.
- Deploying and operating applications with AWS, Cloudflare, Docker, Linux, and CI/CD.
- Prioritizing readable code, application security, performance, and pragmatic system design.
